# 홍보영상 프롬프트 메이커 v2

상품 키워드와 샵 이름만 넣으면 (예: `겨울 코트` / `상아 샵`) 고퀄리티 홍보영상 기획서와 **이미지·영상 AI에 바로 붙여넣을 씬별 프롬프트**를 만들어 주는 데스크탑 앱입니다.

> v1은 [`v1` 브랜치](../../tree/v1)와 `v1.0.0` 태그에 그대로 남아 있습니다.

## v2 기능

- **FLUX 3 → LTX-2.5:** 씬마다 FLUX 3 키프레임(첫 프레임) 이미지 프롬프트와, 그 이미지를 넣어 돌리는 LTX-2.5 이미지-투-비디오 프롬프트(효과음·앰비언스 포함)를 만듭니다. Veo 3·Sora 2·Kling·Runway·범용도 지원합니다.
- **컷 간 일관성 고정:** 상품·인물·배경·조명·톤·사운드마다 "고정 문구"를 정하고 모든 컷 프롬프트에 똑같이 넣습니다. 앱이 컷마다 고정 문구가 빠짐없이 들어갔는지 검사해 `일관성 고정 ✓ 5/5`처럼 표시하고, 컷마다 어떤 이미지를 레퍼런스로 넣을지도 알려 줍니다.
- **참고 이미지 누끼:** 상품·모델·매장 사진을 넣으면 이 PC에서 배경을 지우고(최대 3장), AI가 그 모습을 그대로 고정 문구에 반영합니다. 누끼 PNG는 저장해서 FLUX 3 레퍼런스로 쓸 수 있습니다.

## 실행

```bash
npm install
npm start
```

## 운영자 키로 설치 파일 만들기 (테스트용)

1. 프로젝트 폴더에 `operator-key.txt`를 만들고 운영자 Anthropic API 키(`sk-ant-...`)를 넣습니다. 다른 줄이 섞여 있어도 키 줄만 읽습니다.
2. 설치 파일을 만듭니다.

   ```bash
   npm run dist
   ```

3. `dist\VideoPromoPromptMaker-Setup-2.0.0.exe`를 전달합니다. 받은 사람은 키 입력 없이 바로 씁니다.

> ⚠ 키가 설치 폴더의 `resources\operator-key.txt`에 그대로 들어갑니다. 받은 사람은 누구나 키를 꺼낼 수 있으니 테스트하는 사람에게만 주고, 공개된 곳에 올리지 마세요. Anthropic 콘솔에서 월 사용 한도를 걸어 두세요. 정식 배포 때는 키를 서버에 두는 방식(git 기록 `84b3916`의 `server/`)으로 바꾸는 것이 안전합니다.

## 구조

| 경로 | 역할 |
|---|---|
| `src/metaprompt.js` | **메타프롬프트 본체**: 시스템 프롬프트, 툴별 가이드, 일관성 고정 규칙, 출력 스키마, 입력 검증 |
| `src/generate.js` | Claude 호출(`claude-opus-5-5`, 스트리밍 + 구조화 출력) |
| `src/cutout.js` | 배경 제거(`@imgly/background-removal-node`) |
| `main.js` | Electron 메인 프로세스: 운영자 키 읽기, 생성·누끼 처리 |
| `renderer/` | UI |
